Analytics — visitor dashboard, GA4 & Plausible setup

Your visitor dashboard is live at /dashboard/ (also linked in the main menu and footer). It works with zero backend: it reads only what window.ReelOpalAnalytics records in this browser's localStorage — page views (all time + today), a per-day unique-visitor flag, top titles, top pages, referrer type (search / social / direct / other, from document.referrer plus UTM parameters), smartlink clicks. It is privacy-friendly: no cookies, so no cookie banner is needed. Until GA4 or Plausible is connected, the dashboard shows this browser's own visits only — a per-device estimate, not site-wide traffic.

Connect GA4 (Google Analytics 4) — for real site-wide traffic:

  1. Go to analytics.google.com and sign in with the site's Google account.
  2. Click Admin → Create → Property, name it “ReelOpal”, set your time zone and currency, then choose Web as the platform and enter the site's URL.
  3. Google shows a Measurement ID that looks like G-XXXXXXXXXX — copy it.
  4. Open the site code, find GA_MEASUREMENT_ID at the top (next to SMARTLINK_URL), paste the ID between the quotes, save and redeploy. The dashboard's GA4 status then flips to Connected.

Connect Plausible (privacy-friendly alternative):

  1. Go to plausible.io, create an account and choose Add a website.
  2. Enter the site's domain exactly as Plausible asks (for example reelopal.onrender.com or your custom domain).
  3. Open the site code, find PLAUSIBLE_DOMAIN at the top, paste that same domain between the quotes, save and redeploy. The dashboard's Plausible status then flips to Connected.

Plain note: real site-wide traffic — every visitor, not just this browser — only appears once GA4 or Plausible is connected. Until then, the dashboard honestly shows this browser's own visits only, and shows 0 with “No visits recorded yet on this browser” when nothing has been recorded. Also at deploy: verify the domain in Google Search Console, submit sitemap.xml, and the canonical, robots.txt, sitemap.xml and llms.txt already point at the Render domain — re-point them only if a custom domain is set. You can inspect the local hook anytime with ReelOpalAnalytics.summary() in the browser console.
